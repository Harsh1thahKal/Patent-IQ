# 🌐 Global Innovation Trend Discovery Using Patent Mining and Knowledge Graphs

**PatentIQ** is an AI-powered platform that analyzes patent data to discover emerging technologies, innovation trends, and relationships between patents, organizations, inventors, countries, and technology domains.

🌐 **Live Demo:** https://patent-intelligence-64jf.bolt.host

---

## 📌 Project Overview

This project uses patent mining, data analytics, machine learning, and knowledge graphs to analyze large-scale patent data. It helps identify emerging technologies, technology growth patterns, geographical innovation trends, and relationships between different patent entities.

---

## ✨ Features

* 🔍 Patent search and exploration
* 📊 Interactive innovation trend dashboards
* 🌍 Country-wise patent analysis

* 📈 Emerging technology trend discovery

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

### 2. Install Dependencies

```bash
npm install
```

For the Python backend:

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file and add the required database/API configuration.

```env
DATABASE_URL=your_database_url
API_KEY=your_api_key
```

### 4. Run the Application

```bash
npm run dev
```

Run the backend separately if required:

```bash
python app.py
```
